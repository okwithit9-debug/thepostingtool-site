What it posts

Posts the video and caption from your inbox to an X account you own. You drop a matching video + JSON sidecar, run the go command, and check posted/ or failed/.

Who it is for

People who already have (or will create) an X account and want to post from their own machine. Not for people who want a hosted dashboard to hold the login.

What you need before connect

  • An X account you own, already signed in in regular Chrome.
  • Google Chrome installed.
  • Project folder cloned from GitHub.
  • No Business conversion. X has no Business-account rule in this tool.

How you connect

Run the login helper and sign into X in the window it opens:

python3 setup_playwright_logins.py

X sometimes blocks the helper (Next freezes, or a “verify you are human” page). If that happens, see the warning below and try again.

Cloudflare / verify you are human. Solve the checkbox in regular Chrome, fully quit Chrome, then run the login helper again (or run ./fix_x_cloudflare.command on Mac).

More: Setup guide.

Everyday use

Drop a video and a matching .json sidecar into inbox/ (same base name). Run ./posting_tool_go.command or python3 schedule_batch.py dispatch. Do not run two dispatches at once. Check posted/ or failed/ + screenshots.

Beginner walkthrough: Setup guide → Everyday use.

Limits / account-type warnings

No Business-account rule on X. The usual break is a stale login or a Cloudflare interstitial. Fix the page in regular Chrome, quit Chrome, and sign in again. Never paste passwords or cookies into email or an AI.
